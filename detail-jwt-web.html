Web Tegal Culture

Website backend yang mengintegrasikan seluruh kebutuhan project 8, dibangun dengan Python dan CSS. Website ini berperan sebagai database dan penyedia API real-time untuk data budaya Tegal, sehingga data yang ditampilkan di aplikasi mobile selalu terbarui secara otomatis.

Python CSS API Realtime
Overview

Tentang Proyek

Web Tegal Culture adalah website yang dibangun khusus untuk menjadi tulang punggung (backend) dari aplikasi mobile budaya Tegal pada project 8. Menggunakan Python untuk logika backend dan CSS untuk menata tampilan, website ini menyediakan database dan API real-time yang dikonsumsi langsung oleh aplikasi mobile.

Seluruh data budaya Tegal yang dikelola website ini tersimpan dalam database terpusat dan disajikan melalui endpoint API yang cepat dan stabil. Aplikasi mobile project 8 memanfaatkan API tersebut untuk menampilkan data real-time, sementara keamanan akses dijaga melalui token JWT yang diverifikasi oleh backend. Dengan demikian, arsitektur web dan mobile bekerja sebagai satu kesatuan sistem yang sinkron, aman, dan mudah dikembangkan.

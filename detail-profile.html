Web Profile Kampus

Website profil institusi perguruan tinggi yang dibangun dengan Python Flask sebagai backend, dijalankan melalui server XAMPP, dan diperkaya JavaScript untuk interaktivitas. Website menyajikan visi misi, program studi, fasilitas, hingga berita kampus dalam tampilan yang profesional dan mudah dinavigasi.

Python Flask XAMPP JavaScript
Overview

Tentang Proyek

Web Profile Kampus adalah website profil institusi perguruan tinggi yang menampilkan visi misi, program studi, fasilitas, dan informasi akademik dalam tampilan yang profesional dan representatif. Website ini menjadi pintu gerbang digital bagi calon mahasiswa dan publik untuk mengenal kampus, sekaligus memperkuat citra dan kredibilitas institusi di dunia maya.

Dibangun menggunakan Python Flask sebagai backend dan dijalankan melalui server XAMPP, website ini mampu menangani routing halaman secara dinamis dengan performa yang stabil. JavaScript digunakan untuk memperkaya interaksi pengguna, seperti menu responsif, slider, dan animasi, sementara CSS memastikan setiap halaman tampil konsisten dan elegan di semua perangkat. Seluruh informasi disusun dengan hierarki yang jelas sehingga pengunjung dapat menemukan apa yang mereka cari dengan cepat.

Web Profile Flask

Website profil yang dibangun dengan Python Flask sebagai backend, dikombinasikan dengan HTML, CSS, dan JavaScript untuk tampilan yang modern dan interaktif. Aplikasi dijalankan dan dikembangkan menggunakan Laragon sebagai server lokal, dengan struktur kode modular dan template Jinja2 yang memisahkan logika dari tampilan.

Python Flask JavaScript Laragon
Overview

Tentang Proyek

Web Profile Flask adalah website profil yang menampilkan identitas, keahlian, dan karya dalam tampilan yang bersih, modern, dan mudah dinavigasi. Dibangun menggunakan framework Flask (Python), seluruh halaman dirender secara dinamis melalui routing Flask dan template Jinja2 sehingga struktur website menjadi modular dan terorganisir dengan baik.

Proyek dikembangkan dan dijalankan menggunakan Laragon, menjadikannya mudah untuk dideploy dan diuji di lingkungan lokal. Interaktivitas antarmuka ditingkatkan dengan JavaScript, sementara CSS menata setiap elemen agar responsif di semua perangkat. Arsitektur yang terpisah antara logika aplikasi, template, dan aset statis membuat website ini mudah dikembangkan lebih lanjut, misalnya menambahkan halaman baru, form dinamis, maupun integrasi database.

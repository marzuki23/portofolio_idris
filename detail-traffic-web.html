Web Monitoring YOLOv8

Website monitoring lalu lintas yang menjadi tumpuan utama backend pada project 5. Website menggunakan model YOLOv8 untuk mendeteksi kendaraan secara real-time pada kamera CCTV di Kota Demak, menyajikan data deteksi, statistik kepadatan, serta menyediakan API bagi aplikasi mobile.

Python YOLOv8 OpenCV CCTV
Overview

Tentang Proyek

Web Monitoring YOLOv8 adalah website yang menjadi tumpuan utama (backend) dari aplikasi mobile pada project 5. Sistem ini memanfaatkan model YOLOv8 untuk mendeteksi kendaraan secara real-time pada aliran video kamera CCTV yang tersebar di Kota Demak. Setiap kendaraan yang terdeteksi dihitung dan dicatat, kemudian ditampilkan dalam bentuk statistik dan visualisasi yang mudah dipahami.

Website menyajikan dashboard monitoring yang menampilkan jumlah kendaraan, klasifikasi jenis kendaraan, hingga indikator tingkat kepadatan lalu lintas di setiap titik pantau. Selain sebagai dashboard, sistem juga menyediakan REST API yang dikonsumsi oleh aplikasi mobile (project 5) sehingga data antara web dan aplikasi selalu sinkron. Dengan pendekatan computer vision dan arsitektur backend yang solid, proyek ini menjadi contoh nyata integrasi antara pengolahan citra, web development, dan aplikasi mobile.

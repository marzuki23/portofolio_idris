Mobile App UMKM

Aplikasi penjualan produk UMKM yang dibangun dengan Flutter dan Dart, menggunakan Supabase sebagai backend (database, autentikasi, dan penyimpanan file) serta Google Console untuk fitur login dengan akun Gmail. Aplikasi menghadirkan katalog produk, keranjang belanja, dan proses pemesanan yang sederhana bagi para pelaku usaha kecil.

Flutter Dart Supabase Google Console
Overview

Tentang Proyek

Mobile App UMKM adalah aplikasi penjualan produk usaha mikro, kecil, dan menengah yang dibangun menggunakan Flutter dan Dart. Aplikasi ini dirancang agar pelaku UMKM dapat menjual produknya secara mobile dengan mudah, sementara pembeli dapat menjelajahi katalog, menambahkan produk ke keranjang, dan melakukan pemesanan langsung dari smartphone.

Backend aplikasi menggunakan Supabase, sebuah platform open-source berbasis PostgreSQL, untuk menyimpan data produk, pesanan, dan akun pengguna sekaligus menyediakan autentikasi dan penyimpanan file (storage). Fitur login dengan akun Gmail dikonfigurasi melalui Google Console, sehingga pengguna dapat masuk dengan cepat dan aman tanpa harus mendaftar manual. Dengan satu basis kode Dart, aplikasi berjalan mulus di Android dan iOS, menghadirkan pengalaman berbelanja yang modern, responsif, dan siap dikembangkan lebih lanjut.

Tampilan Aplikasi

  • Login GoogleMasuk cepat menggunakan akun Gmail melalui Google Console.
  • HomeHero dan produk unggulan dari berbagai UMKM.

Keunggulan

  • Backend Supabase: database, autentikasi, dan storage dalam satu platform.

  • Satu basis kode Flutter untuk Android dan iOS.
  • Widget modular dan siap dikembangkan dengan fitur baru.

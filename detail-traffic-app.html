Mobile App Monitoring

Aplikasi mobile monitoring yang dibangun dengan Flutter dan Dart, menampilkan data deteksi kendaraan dari CCTV secara real-time. Backend menggunakan Firebase dan API server web, dikonfigurasi melalui Google Console, serta terintegrasi penuh dengan website monitoring pada project 6 sehingga seluruh data selalu sinkron.

Flutter Dart Firebase Google Console
Overview

Tentang Proyek

Mobile App Monitoring adalah aplikasi mobile yang dibangun menggunakan Flutter dan Dart untuk memantau kondisi lalu lintas melalui data deteksi kendaraan pada kamera CCTV. Aplikasi menampilkan jumlah kendaraan terdeteksi, status kepadatan, dan informasi lalu lintas lainnya secara real-time dengan antarmuka yang modern dan mudah digunakan.

Backend aplikasi memanfaatkan Firebase untuk penyimpanan dan otentikasi, dikonfigurasi melalui Google Console untuk layanan Google seperti login, dan terhubung ke server web yang menjadi API utama. Server tersebut (project 6) memproses deteksi kendaraan menggunakan model YOLOv8, sehingga aplikasi mobile ini menerima data yang akurat dan selalu terkini. Dengan satu basis kode Dart, aplikasi berjalan mulus di berbagai perangkat dan terus sinkron dengan data dari website monitoring.

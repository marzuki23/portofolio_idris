Mobile App Tegal Culture

Aplikasi mobile tentang budaya Tegal yang dibangun dengan Flutter dan Dart, menggunakan Supabase sebagai backend, Google Console untuk layanan Google, dan JWT sebagai keamanan token. Flutter Dart Supabase JWT
Overview

Tentang Proyek

Mobile App Tegal Culture adalah aplikasi mobile yang dibangun menggunakan Flutter dan Dart untuk memperkenalkan budaya Tegal kepada masyarakat. Aplikasi dibangun dengan sistem keamanan yang ketat: backend menggunakan Supabase untuk otentikasi dan penyimpanan, layanan Google dikonfigurasi melalui Google Console, dan setiap akses pengguna diamankan menggunakan token JWT sehingga hanya pengguna terverifikasi yang dapat mengakses data.

Bagian menarik dari proyek ini adalah arsitekturnya yang terintegrasi penuh dengan project 9. Website pada project 9 berperan sebagai database dan penyedia API real-time, sehingga setiap perubahan data budaya di server langsung tercermin di aplikasi mobile. Dengan kombinasi Flutter, Supabase, JWT, dan API real-time, proyek ini menunjukkan implementasi nyata aplikasi mobile yang aman, dinamis, dan terhubung langsung dengan backend web.
